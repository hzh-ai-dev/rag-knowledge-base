# 云雀智答 产品手册（v3.2）

## 一、产品简介

云雀智答（SkylarkQA）是云雀智能面向企业推出的知识库问答产品，基于检索增强生成（RAG）架构，
让大模型能够基于企业内部文档作答，并给出可追溯的引用来源。

产品于 2024 年 3 月发布 1.0 版本，2026 年 1 月发布 3.0 大版本，当前最新版本为 v3.2。

## 二、核心能力

1. **多格式文档解析**：支持 PDF、Word（docx）、Markdown、纯文本四类格式。单个文件默认上限 32MB。
2. **混合检索**：向量语义检索与 BM25 关键词检索并行执行，采用 RRF（Reciprocal Rank Fusion）融合结果，
   专有名词与型号类查询的召回率相比纯向量检索提升约 23%。
3. **引用溯源**：每条回答标注来源文件与页码，用户可点击查看原文片段。
4. **流式输出**：基于 SSE 逐字返回，首字节延迟平均 380 毫秒。
5. **多轮对话**：默认携带最近 6 轮上下文，可通过配置调整。

## 三、技术规格

| 项目 | 规格 |
| --- | --- |
| 向量模型 | text-embedding-3-small（1536 维），可切换本地 bge-small-zh-v1.5（512 维） |
| 默认分块大小 | 700 字符，重叠 120 字符 |
| 默认召回数量 | top_k = 6，候选池 20 |
| 向量数据库 | ChromaDB（本地持久化），支持替换为 Qdrant / Milvus |
| 并发能力 | 单实例 4 核 8G 配置下，稳定支撑 30 QPS 的问答请求 |

## 四、版本历史

- **v3.2**（2026-08）：新增重排（Rerank）开关；修复 PDF 表格解析丢失的问题。
- **v3.1**（2026-05）：支持上传即入库，无需重启服务；新增文档删除接口。
- **v3.0**（2026-01）：重构为混合检索架构；引入引用溯源。
- **v2.0**（2025-06）：支持多轮对话与流式输出。
- **v1.0**（2024-03）：首个正式版本，仅支持纯向量检索与单轮问答。

## 五、部署方式

支持两种部署形态：

- **SaaS 版**：开箱即用，按量计费，标准版 ￥0.02 / 千 tokens，专业版 ￥0.05 / 千 tokens。
- **私有化版**：部署在客户内网，数据不出域，按年授权，起步价 ￥18 万 / 年（含 3 个实例）。

私有化版本要求最低配置为 8 核 16G、50GB 磁盘，并需要能够访问所选大模型厂商的 API 网关；
若采用本地向量模型，则可完全离线运行。
